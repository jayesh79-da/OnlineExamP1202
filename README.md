# 🎓 Online Exam Portal System

## 📌 Project Overview
The **Online Exam Portal System** is a web-based application developed to conduct examinations digitally in a secure, efficient, and automated manner. The system eliminates traditional paper-based exams and manual evaluation by providing a centralized online platform for administrators and students.

This project is built using **Java (Servlets & JSP), MySQL, HTML, CSS, and JavaScript**, and runs on **Apache Tomcat Server**.

---

## 🚀 Features

### 👨‍💼 Admin Module
- Add, update, and delete exams
- Add multiple-choice questions
- Manage student accounts
- View student results
- Control exam settings and duration
- Monitor active users

### 👨‍🎓 Student Module
- Secure registration and login
- View available exams
- Attempt timed examinations
- Automatic answer evaluation
- Instant result display
- Download generated certificate (if passed)

### 🏆 Automatic Certificate Generation
After successful exam completion:
- Score is calculated automatically
- Certificate is generated instantly
- Includes:
  - Student Name
  - Exam Name
  - Score/Grade
  - Date of Completion
  - Unique Certificate ID

### 🤖 Simple Chatbot (Website Help Assistant)
A basic chatbot is integrated to help users with:
- Registration guidance
- Login assistance
- How to start an exam
- Certificate download help
- Frequently asked questions

## 🔄 Working Flow
1. User registers or logs into the system.
2. Student selects an available exam.
3. Questions are displayed with a timer.
4. Student submits answers.
5. System evaluates automatically.
6. Result is displayed instantly.
7. If passed, certificate is generated.
8. Chatbot assists users if required.
